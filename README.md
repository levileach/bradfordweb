# Bradford Web

A single-page freelance web design website targeting small businesses in New York City.

## Overview

Static HTML/CSS landing page for a web design freelancer. Features a clean, minimal editorial aesthetic using DM Serif Display and DM Sans typefaces.

## Sections

- **Hero** — Tagline and call-to-action
- **Services** — Website Design & Build, Local SEO & AI Visibility, Ongoing Support
- **About** — Freelancer background and value proposition
- **Contact** — Netlify form for lead capture

## Tech

- Pure HTML/CSS — no frameworks, no dependencies
- Google Fonts (DM Serif Display, DM Sans)
- Netlify Forms for contact form handling
- Scroll-triggered fade-in animations via IntersectionObserver

## Deployment

Deploy to [Netlify](https://netlify.com) by connecting this repo. The contact form uses `data-netlify="true"` and will work automatically once deployed to Netlify.

## Customization

Replace all instances of `[Your Name]` in `index.html` with the actual name before going live.
